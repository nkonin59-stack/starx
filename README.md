# StarX Mini App — полный проект

Тёмный интерфейс StarX с золотым акцентом и PNG-изображениями в `frontend/public/assets/`.

## Что включено
- Главная, задания, мини-игры (рулетка, мины, краш), билетики, розыгрыши, рейтинг, NFT-каталог и профиль.
- Промокоды: пользователь может активировать доступный код один раз; в админке можно создавать, выключать и удалять коды.
- Админ-панель: PIN демо-режима `0000`, начисление/списание звёзд текущего демо-профиля, создание/удаление/сброс заданий и настройки краша.
- Состояние интерфейса сохраняется в `localStorage` браузера.
- Backend FastAPI/SQLite и пример Telegram-бота на aiogram находятся в `backend/` и `bot/`.

## Запуск локально
1. Установи Node.js 20+.
2. Открой терминал в папке `frontend`.
3. Выполни `npm install`.
4. Выполни `npm run dev`.
5. Для проверки сборки: `npm run build`.

## Cloudflare Workers
- Root directory: `/`
- Build command: `npm run build` (или `cd frontend && npm install && npm run build`)
- Deploy command: `npx wrangler deploy`
- Конфигурация ассетов находится в корневом `wrangler.jsonc`.

## ВАЖНО: границы демо
Этот проект даёт рабочий интерактивный демоинтерфейс, но не является готовой денежной платформой. Баланс, задания, промокоды и результаты игр на фронтенде нельзя считать защищёнными: `localStorage` можно изменить, а PIN `0000` не является настоящей серверной авторизацией. Перед публичным запуском нужно перенести начисление наград, проверку заданий/подписок, промокоды, баланс и исходы игр на backend; проверять Telegram `initData` на сервере; закрыть административные API авторизацией. Реальные Telegram Stars-платежи и NFT-сделки не подключены. Игры работают в деморежиме, без реальных денежных операций.
