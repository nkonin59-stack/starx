# StarX Complete — фронтенд + backend API

Проект включает адаптивный интерфейс, PNG-ассеты, Telegram Mini App авторизацию с серверной HMAC-проверкой, серверную базу SQLite, защищённую по Telegram ID админ-панель, CRUD каталога/заданий/промокодов, загрузку изображений, редактирование цен/остатков, профиль и серверные записи начислений. Раздел «Билетики» удалён. В играх оставлен только виртуальный демо-режим.

## Важно — это не готовая торговая биржа

Каталог и административные инструменты работают с данными StarX, но цены по умолчанию демонстрационные. Для настоящих NFT-листингов, оформления покупки/передачи подарка, платежей и вывода нужны отдельный источник листингов и платёжная/Telegram интеграция. В проекте специально нет фиктивной кнопки, которая притворяется реальной покупкой. Проверка подписок и рефералов тоже требует настроить Telegram-бота и Bot API; такие задания API пока не начисляет без проверки.

## 1. Подготовь Telegram-бота

1. Создай/выбери бота через `@BotFather`.
2. Включи Mini App / укажи Web App URL после публикации.
3. Скопируй bot token в секретные переменные backend. Не помещай токен в frontend, GitHub или `VITE_*` переменные.
4. Узнай свой числовой Telegram ID и задай его в `ADMIN_TELEGRAM_IDS` (если несколько ID — через запятую). Только эти ID получают доступ к админке.

## 2. Backend (Render)

В корне проекта есть `render.yaml`. Импортируй репозиторий в Render как Blueprint и задай секреты:

- `TELEGRAM_BOT_TOKEN` — токен бота от BotFather.
- `ADMIN_TELEGRAM_IDS` — твой числовой Telegram ID.
- `PUBLIC_API_URL` — полный публичный URL API, например `https://starx-api.onrender.com` (без `/` в конце).
- `CORS_ORIGINS` — URL фронтенда Cloudflare, например `https://starx.nkonin59.workers.dev`.
- `DEV_AUTH=false` — обязательно для production.

Blueprint задаёт постоянный диск `/var/data` для SQLite и загруженных изображений. Не удаляй его, иначе потеряешь данные. Если бесплатный тариф не поддерживает постоянный диск для выбранного сервиса, используй PostgreSQL + объектное хранилище для изображений перед запуском.

Проверь `https://ТВОЙ-API/api/health`: ожидается `{"ok":true,...}`.

## 3. Cloudflare Workers

В Cloudflare Workers & Pages → `starx` → Settings → Variables and Secrets добавь **Build variable** `VITE_API_URL` со значением полного URL backend, например `https://starx-api.onrender.com`. Это публичный URL API, не секрет. Секреты бота должны оставаться только в Render.

Build command:

```sh
cd frontend && npm install && npm run build
```

Deploy command:

```sh
npx wrangler deploy
```

Root directory: `/`. После сохранения переменной запусти новую сборку. В `render.yaml` также замени `CORS_ORIGINS` на фактический URL Worker.

## 4. Локальный запуск

Frontend:

```sh
cd frontend
npm install
npm run dev
```

Backend в другом терминале:

```sh
cd backend
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Создай переменные окружения `TELEGRAM_BOT_TOKEN`, `ADMIN_TELEGRAM_IDS`, `DEV_AUTH=true`, затем `uvicorn main:app --reload --port 8000`. Запусти Vite с `VITE_API_URL=http://localhost:8000`. DEV_AUTH использовать только локально; не включать на публичном сервере.

## Функции админки

- Маркет: добавить/редактировать/удалить карточку, название, описание, цену, категорию, редкость, остаток, активность и PNG/JPG/WebP до 5 МБ.
- Задания: создавать, редактировать, выключать и удалять задания с наградой.
- Промокоды: создавать, редактировать, выключать и удалять коды; награда, лимит активаций, один код на пользователя.
- Настройки: название, валюта, текст главной, включение маркета/игр и параметры демо-игр.
- Профиль: Telegram ID, баланс, активация промокода.

## Безопасность и ограничения

- Telegram `initData` проверяется HMAC-подписью на сервере и ограничивается по времени.
- Админ-доступ проверяется на сервере по `ADMIN_TELEGRAM_IDS`, а не по кнопке/параметру браузера.
- Баланс нельзя менять публичным произвольным запросом; все начисления, предусмотренные сейчас, создаются сервером.
- Настрой постоянное хранилище. Локальные PNG по умолчанию в каталоге `frontend/public/assets` — они входят в сборку.
- Не используй демо-игры как ставки на реальные деньги/ценности. Они не реализуют честную игровую математику, выплаты или аудит.
